# Salle Saint-Pierre

Single-page website for Salles Saint-Pierre de Pontarlier, a venue rental service in France.
[🔗 Link](https://parriauxmaxime.github.io/bona-fide-vibe/)

## Stack

- Claude (this is fully vibed)
- React 19
- TypeScript
- Tailwind CSS 4
- Rspack
- Biome (lint/format)

## Get Started

```bash
# Install dependencies
yarn

# Start dev server
yarn start

# Build for production
yarn build

# Lint & format check
yarn lint
```

## Deploy

Automated via GitHub Actions to GitHub Pages on push to `main`.
